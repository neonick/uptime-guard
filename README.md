# Независимый монитор

Планировщик — GitHub Actions, стандартный Linux runner каждые пять минут.
Отдельный публичный репозиторий содержит только этот общий монитор; исходники
приложений, адреса проверок, адрес почты, токены и ключи в него не входят.
Конфигурация — GitHub Actions secrets. Состояние содержит только технические
идентификаторы target-1/target-2, результаты и время завершения, без URL/секретов.

Проверяются TLS, точный HTTP200 и JSON status=ok из runner; отдельно явно выбранные российские
узлы check-host. Российский HTTP200 не объявляется проверкой JSON. Недоступность
узлов или API — UNKNOWN, а работающий иностранный маршрут не подавляет отказ РФ.
Telegram отправляется напрямую. Резерв — существующая операторская почта Postbox
из runner, без функции или relay на проверяемом VPS. Это резерв относительно
Telegram, а не второй независимый от Яндекса почтовый провайдер.

Публичные стандартные runners бесплатны; расписание GitHub может задерживаться.
Это не SLA пяти минут. Облачный контур должен проверять timestamp этого монитора,
а этот монитор — completion heartbeat облака. Порог молчания: два периода300с
плюс deadline180с для GitHub; для облака — два периода300с плюс deadline90с.

Первый запуск вручную с bootstrap=true. Синтетические down/recovery используют
другой файл состояния. Настоящие сайты не отключаются. Перед публикацией
подтверждаются видимость репозитория и операторские каналы; перед готовностью —
две автоматические проверки и квитанции alert/recovery.

Источники: [бесплатные runners](https://docs.github.com/en/billing/concepts/product-billing/github-actions),
[расписания и задержки](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule),
[российские узлы](https://check-host.net/about/api),
[Postbox](https://yandex.cloud/en/docs/postbox/operations/send-email).

Общий deadline165с при job timeout180с. На наблюдения выделено80с, поровну между целями и peer; остальные операции ограничены оставшимся общим deadline. UNKNOWN при исчерпании бюджета РФ сохраняется отдельным наблюдением, после него остаётся время на durable state и доставку. Проверки201/202/204 с JSONok не считаются health.
